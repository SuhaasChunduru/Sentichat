# SentiChat

A browser-based **chat bot UI** with a clean, themeable interface. SentiChat provides
a modern chat front end — message bubbles, a sidebar, light/dark themes, and Markdown
rendering — in a single self-contained HTML file.

## Features

- **Single-file app** — everything lives in [`Sentichat.html`](Sentichat.html); no
  build step.
- **Light & dark themes** via CSS custom properties (`data-theme`).
- **Markdown rendering** of responses using [marked.js](https://marked.js.org/).
- **Font Awesome** icons and Google Fonts (Poppins / Lobster) for styling.
- Responsive chat layout with a sidebar and gradient-styled message bubbles.

## Run

Open the HTML file directly in a browser:

```bash
open Sentichat.html   # macOS
# or double-click the file
```

No server or installation required.
